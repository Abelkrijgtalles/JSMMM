# JUST SHOW ME MY MAP!
Shows your map while rowing a boat. That's it. It only applies to maps, and not anything else (more configuration will come in the future).

This was made mostly for making it easier to use buried treasure maps. Now you don't have to stop to look if you are close to the buried treasure.

## Disclaimer
On some servers and in some scenarios this mod is bannable. This is because it technically gives an unfair advantage (looking at a map while actively rowing). Furthermore, there is currently a "bug" (if that's what you want to call it), which makes you able to use other items in a boat if you have a map in your offhand. This will be fixed in a later update.

As I said, the chance of this mod being bannable is near zero (it mostly depends on how you use it), but I'm still putting this disclaimer here because it technically gives an unfair advantage. If you want to know for sure if this is bannable, contact your server admin.
